# Expo SDK 56

This project targets **Expo SDK 56** (pinned to match the public Expo Go in the app stores).
Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

Do NOT upgrade to SDK 57+ unless the store Expo Go supports it — a newer SDK than Expo Go
causes "Project is incompatible with this version of Expo Go".
